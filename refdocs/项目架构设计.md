## 1. 系统架构概览

## 2. 核心功能模块

### 2.1 认证授权模块

| 组件 | 功能描述 |
|------|----------|
| JWT 认证 | 无状态 Token，存储在 localStorage 和 HTTP Header |
| 登录流程 | 用户名/密码 + 图形验证码 → JWT Token |
| Token 验证 | 后端 Base 控制器验证，白名单机制 |
| Session 管理 | PHP Session 用于服务端状态管理 |
| 权限加载 | 登录成功后加载用户权限树 |

### 2.2 权限管理模块

| 组件 | 功能描述 |
|------|----------|
| 权限表 | 4 种权限类型（目录/菜单/按钮/API）|
| 角色表 | 定义角色，支持多对多关系 |
| 权限指令 | `v-permission` 前端指令控制按钮显示 |
| 动态菜单 | 根据用户权限动态生成左侧菜单 |
| 动态路由 | 根据权限动态注册路由，实现页面级权限控制 |
| 权限 Composable | `usePermission()` 组合式函数提供权限检查 |

### 2.3 系统配置模块

| 组件 | 功能描述 |
|------|----------|
| 配置表 | 按分组管理（未定义/站点/运营/系统参数）|
| 配置类型 | text/number/boolean/textarea |
| 配置缓存 | 24 小时缓存，修改后手动清除 |
| 全局调用 | `config('DBC_code')` 方式全局使用 |

### 2.4 定时任务模块

| 组件 | 功能描述 |
|------|----------|
| 定时任务表 | Cron 表达式配置 |
| 执行模式 | API / CLI 双模式 |
| 执行记录表 | 记录执行时间、耗时、状态、输出内容 |
| 执行类型 | execute_type 区分 API(1) 和 CLI(2) |

### 3.2 状态管理 (Pinia)

#### Admin Store (`store/modules/admin.ts`)
- **状态**: `token`, `adminInfo`
- **方法**: `login()`, `logout()`, `setToken()`, `setAdminInfo()`
- **持久化**: localStorage

#### Permission Store (`store/modules/permission.ts`)
- **状态**:
  - `permissions` - 所有权限（树形结构）
  - `menus` - 菜单权限 (type=1,2)
  - `routes` - 路由权限 (type=2)
  - `buttonCodes` - 按钮权限 (type=3)
  - `apiCodes` - 接口权限 (type=4)
  - `loaded` - 权限是否已加载
  - `loading` - 权限是否正在加载
- **方法**: `loadPermissions()`, 权限检查方法

#### Tabs Store (`store/modules/tabs.ts`)
- **状态**: `tabs`, `activeTab`
- **方法**: `addTab()`, `removeTab()`, `setActiveTab()`, `closeOtherTabs()`

### 3.3 路由系统

#### 静态路由
- `/login` - 登录页（无需认证）

#### 动态路由加载流程
```
登录成功 → loadPermissions() → 解析权限树 → 生成路由配置 → router.addRoutes()
                                                    ↓
                                          前端路由守卫检查权限
```

#### 路由元信息
```typescript
meta: {
  title: '页面标题',
  requiresAuth: true,    // 是否需要认证
  affix: true           // 是否固定标签（不可关闭）
}
```

### 3.4 工具函数 (`utils/commonUtils.ts`)

**日期时间工具**:
- `isToday()` - 判断是否为今天
- `formatTimestamp()` - 格式化为 YYYY-MM-DD HH:mm:ss
- `formatDate()` - 格式化为 YYYY-MM-DD
- `formatTime()` - 格式化为 HH:mm:ss
- `getRelativeTime()` - 相对时间描述

**状态工具**:
- `getStatusTagType()` - Element Plus Tag 类型
- `getStatusText()` - 状态文本
- `STATUS_OPTIONS` - 状态选项数组
- `Status` 枚举

**通用工具**:
- `deepClone()` - 深拷贝
- `debounce()` - 防抖
- `throttle()` - 节流
- `formatFileSize()` - 文件大小格式化
- `generateId()` - 唯一 ID 生成

### 3.5 通用组件

**StatusTag.vue** (`components/Common/StatusTag.vue`)
- 统一的状态标签展示组件
- 支持 success/danger/info/warning 类型

**CronSelector.vue** (`components/System/CronSelector.vue`)
- Cron 表达式选择器
- 可视化配置定时任务规则

### 4.2 控制器层架构

#### Base 控制器 (`admin/controller/Base.php`)
**职责**:
- CORS 跨域处理
- JWT Token 验证
- 权限检查（超级管理员放行）
- 用户信息注入到请求对象

**白名单机制**:
```php
protected $tokenWhiteList = array(
    'admin/login/submit',    // 登录接口
    'admin/captcha/index',  // 验证码接口
);
```

#### Common Base 控制器 (`common/controller/Base.php`)
**职责**:
- 配置缓存自动加载
- 统一的响应格式
- 公共基础功能

### 4.3 辅助类

#### Jwt Helper (`admin/helper/Jwt.php`)
**功能**:
- JWT Token 生成
- JWT Token 解析和验证
- Token 过期检查

### 4.4 架构说明

**简化三层架构**:
- 控制器层直接包含业务逻辑
- 不单独抽取 Service 层
- 控制器通过 Model 层访问数据库
- 遵循 `禁止在 Controller 中直接使用 M() 函数` 规范

## 5. 核心创新点

### 5.1 动态权限驱动架构 🔥

**核心创新**: 前端完全由后端权限数据驱动

**技术优势**:
- 权限存储在数据库，可通过后台动态修改
- 支持 4 种权限类型（目录、菜单、按钮、API）
- 权限与角色解耦，多对多关系
- 前端菜单/路由/按钮全部动态生成
- 权限指令 `v-permission` 精细化按钮级控制

**数据流**:
```
后端 bms_permissions 表
         ↓
getUserPermissions API
         ↓
前端 permission store
         ↓
  ┌──────┴──────┬──────────┐
  ↓             ↓            ↓
菜单树        动态路由      按钮权限
Sidebar     Router      v-permission
```

### 5.2 多标签页导航系统

**核心创新**: 实现浏览器式多标签页管理

**功能特性**:
- 标签自动添加（路由跳转时）
- 标签关闭（右键菜单、关闭按钮）
- 固定标签（不可关闭）
- 标签激活状态管理

### 5.3 定时任务双执行模式

**核心创新**: API 和 CLI 双执行模式

**技术实现**:
- `execute_type` 字段区分执行方式
- CLI 模式通过 `exec()` 执行 PHP 命令
- 执行记录表精确追踪耗时和输出

## 6. 数据库设计

### 6.1 表清单

**核心表（5 张）**:
- `bms_admins` - 管理员表

**总计: 8 张表**

### 6.2 权限类型约定

| type 值 | 说明 | code 命名规则 | 示例 |
|-------|------|-------------|--------|
| 1 | 目录 | {模块名} | Workspace, System |

## 7. 开发规范

### 7.1 PHP 5.6 兼容性

**⚠️ 严禁使用 PHP 7+ 语法**

禁止语法:
- `$var ?? $default` - 空合并运算符
- `function foo(int $a): int` - 类型声明
- 匿名类 - 匿名类语法
- Group use - Group use 语句

### 7.2 命名规范

| 类型 | 命名规则 | 示例 |
|------|----------|------|
| 控制器 | 大驼峰 | `Admin.php`, `Login.php` |
| 模型 | 大驼峰 | `Admin.php`, `Permission.php` |
| 方法 | 小驼峰 | `getList()`, `verifyPassword()` |
| 变量 | 小写+下划线 | `$admin_id`, `$user_name` |

| 类型 | 命名规则 | 示例 |
|------|----------|------|
| 组件 | 大驼峰 | `UserList.vue`, `SidebarItem.vue` |
| 文件夹 | 小写 | `api/`, `utils/`, `views/` |
| TS 文件 | 小驼峰 | `usePermission.ts`, `request.ts` |
| 常量 | 大写+下划线 | `API_BASE_URL` |

### 7.3 统一响应格式

**成功响应**:
```php
return json(array(
    'code' => 200,
    'msg' => '操作成功',
    'data' => $data
));
```

**错误响应**:
```php
return json(array(
    'code' => 400,
    'msg' => '错误信息',
    'data' => null
));
```
